# Elastic SIEM SOC Homelab

### Cybersecurity Portfolio | Phase 1

## Project Overview

Designed, deployed and operated a virtual Security Operations Centre (SOC) environment using Elasticsearch, Kibana, Fleet Server, Windows 11 and Kali Linux.

The project was developed to gain practical experience in security monitoring, detection engineering, threat investigation and incident response.

Using an isolated three-machine VirtualBox environment, I configured centralised Windows Security log collection, developed a custom detection rule and conducted controlled authentication attack simulations to evaluate the monitoring infrastructure.

The project progressed through the complete SOC workflow:

**Infrastructure Deployment → Log Collection → Detection Engineering → Attack Simulation → Incident Investigation → Risk Assessment → Remediation**

The investigation included a Hydra password-guessing simulation that generated three failed Windows authentication events followed by one successful network authentication. The activity was detected, investigated, documented and closed within Elastic Security.

The project also includes a structured security risk assessment, remediation recommendations and mappings to relevant ISO/IEC 27001:2022 controls.

### Lab Infrastructure

The environment consists of three virtual machines connected through a private `192.168.56.0/24` Host-Only network.

- **Ubuntu SOC Server (`192.168.56.10`)** — Elasticsearch, Kibana and Fleet Server.
- **WindowsEndpoint (`192.168.56.101`)** — Windows Security logging and Fleet-managed Elastic Agent.
- **Kali-Attack (`192.168.56.102`)** — Network reconnaissance and controlled authentication simulations.

Each virtual machine also uses a NAT adapter for internet connectivity.

## Key Project Achievements

### 1. SOC Infrastructure Deployment
- Built a three-VM cybersecurity homelab using Oracle VirtualBox.
- Deployed Elasticsearch, Kibana and Fleet Server on Ubuntu Server.
- Configured an isolated network environment for security monitoring and controlled attack simulations.
- Troubleshot TLS certificate validation, Fleet connectivity and Kibana encryption configuration.
- Optimised Elasticsearch memory allocation and expanded Ubuntu storage using LVM.

### 2. Centralised Security Monitoring
- Deployed and enrolled a Windows Elastic Agent through Fleet.
- Configured Windows Security, System and Application event collection.
- Verified successful ingestion of Windows authentication events into Elasticsearch.
- Used Kibana Discover and KQL to search and analyse security telemetry.

### 3. Custom Detection Engineering
- Developed a threshold-based detection rule named **Repeated Windows Failed Logons**.
- Configured the rule to detect three or more failed authentication events targeting the same username.
- Successfully generated and validated Medium-severity security alerts.
- Evaluated false positives, detection limitations and opportunities for improvement.

### 4. Controlled Attack Simulation
- Performed Nmap reconnaissance and validated Windows Firewall restrictions.
- Configured restricted SMB access for controlled authentication testing.
- Generated remote authentication failures using SMBClient.
- Conducted a Hydra password-guessing simulation against a temporary Windows account.
- Verified three failed authentication attempts followed by one successful network authentication.

### 5. SOC Incident Investigation
- Investigated security alerts generated by the custom detection rule.
- Analysed Windows Security Events 4625 and 4624.
- Identified the source of authentication activity using IP addresses, workstation names and authentication details.
- Correlated failed authentication events with a subsequent successful logon.
- Documented investigation findings and closed the resulting alerts.

### 6. Risk Assessment & Remediation
- Evaluated security risks associated with SMB exposure and password guessing.
- Recommended authentication, network security and monitoring improvements.
- Removed temporary test accounts, password files and firewall permissions following testing.
- Identified outstanding remediation verification requirements.
- Mapped relevant technical findings to ISO/IEC 27001:2022 Annex A controls.

### Project Outcome

Successfully developed and validated an end-to-end SOC monitoring and investigation environment, demonstrating practical experience across infrastructure deployment, security telemetry collection, detection engineering, controlled attack simulation, incident investigation and risk assessment.
